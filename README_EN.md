FlashForge Group, a long-established Chinese 3D printer manufacturer, is hiring a Klipper firmware development engineer to drive Klipper-based firmware development and mass-production deployment across our full printer lineup (CoreXY / SCARA / Delta).

## Responsibilities

1. Develop and customize the control system for our 3D printer models (CoreXY / SCARA / Delta, etc.) based on the open-source Klipper firmware;
2. Build high-performance motion control modules, custom peripheral drivers, and Host-MCU communication protocol extensions using C++11 or later;
3. Tune printer motion control parameters — including Input Shaping, Pressure Advance, and acceleration curves — to resolve print quality issues such as resonance, layer lines, and stringing;
4. Work with the hardware team on bring-up and integration of new mainboards, TMC drivers, thermistors, ADXL345, and other peripherals;
5. Write G-code macros, extend Moonraker interfaces, and develop automated test scripts; deliver production configuration files and tuning SOPs;
6. Track Klipper upstream releases, evaluate new features, and drive internal firmware version iteration.

## Requirements

1. 3+ years of experience; Bachelor's degree or above in Computer Science, Electronic Engineering, Electrical, Automation, or Mechatronics;
2. Solid C++11+ skills — smart pointers, lambdas, rvalue references, std::thread / std::mutex — with embedded or real-time system C++ development experience;
3. Familiar with Python; able to read and modify Klipper host-side code (`klippy/`); knowledge of C and MCU-side source (`src/`) is a plus;
4. Experience with at least one of Marlin, Repetier, or Klipper firmware, with real project delivery experience;
5. Understanding of motion planning algorithms (trapezoidal acceleration, S-Curve, Input Shaping) with hands-on tuning capability;
6. Proficient with Git; basic Linux operations (e.g., serial port configuration);
7. Solid work ethic, strong hands-on and problem-solving skills; experience with oscilloscope / logic analyzer is a plus.
