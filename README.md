闪铸集团（FlashForge）诚聘 Klipper 固件开发工程师，负责公司全系列 3D 打印机（CoreXY / SCARA / Delta）的 Klipper 固件二次开发与量产落地。

## 工作职责

1. 基于 Klipper 开源固件进行二次开发，完成公司 3D 打印机型（CoreXY / SCARA / Delta 等）的控制系统适配与功能定制；
2. 使用 C++11 及以上标准开发高性能运动控制模块、自定义外设驱动及 Host-MCU 通信协议扩展；
3. 负责打印机运动控制参数调优，包括 Input Shaping、Pressure Advance、加减速曲线等，解决打印共振、层纹、拉丝等质量问题；
4. 配合硬件团队完成新主控板、TMC 驱动、温度传感器、ADXL345 等外设的底层适配与联调；
5. 编写 G-code 宏命令、Moonraker 接口扩展及自动化测试脚本，输出量产用配置文件与调优 SOP；
6. 跟进 Klipper 上游版本更新，评估新特性并推动内部固件版本迭代。

## 任职资格

1. 3 年以上经验，本科及以上学历，计算机、电子、电气、自动化或机电相关专业；
2. 熟练掌握 C++11 及以上标准，熟悉智能指针、Lambda 表达式、右值引用、std::thread / std::mutex 等现代 C++ 特性，有嵌入式或实时系统 C++ 开发经验；
3. 熟悉 Python 编程，能阅读并修改 Klipper Host 端代码（klippy/ 目录）；了解 C 语言，能看懂 MCU 端源码（src/ 目录）者优先；
4. 熟悉 Marlin、Repetier 或 Klipper 中至少一种 3D 打印固件，有实际项目落地经验；
5. 了解梯形加减速、S-Curve、Input Shaping 等运动规划算法，具备实测调优能力；
6. 熟练使用 Git，了解 Linux 基础操作（串口配置等）；
7. 工作踏实，有较强的动手能力和问题排查意识，能使用示波器 / 逻辑分析仪者优先。
